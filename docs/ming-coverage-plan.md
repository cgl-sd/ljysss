# 内容扩展规划

## 已有范围

应用当前以《明史》332 卷、中文维基百科与 CBDB 为三条资料线，正式发布 2,157 名人物、100 件精选事件、20 个机构及 22 条典章。人物、事件和天下资料均来自同一内容资料库。

## 后续扩展顺序

1. 事件库已重建为 100 件精选大事；后续仅在取得可靠年代、地点、人物与出处时新增，且必须保留背景、经过、相关人物、结果、影响五个分栏。
2. 机构与典章已分别扩展至 20、22 条；后续优先补入能形成独立详情页与可靠出处的职官、制度、器物和宫陵条目。
3. 继续补入有中文维基百科实体并能通过《明史》锚点确认的明朝、南明人物；不以数量目标替代人物准入规则。
4. 只在取得准确历史 GIS 边界与年代范围后扩展可切换地图图层；在此之前维持现有明代舆图，不以临时文字图层冒充地理数据。

## 完成条件

每一批新增内容均须完成来源登记、分类或分栏校验、JSONL 导出、SQLite 重建、后端测试和 Android 构建验证。具体结构规则以 `docs/data-audit.md` 为准，当前数据统计以 `docs/ming-inventory.md` 为准。
