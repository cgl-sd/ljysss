# 两京一十三省 · 本轮界面核对

## 范围

- 设备：Pixel 8 模拟器，1080 × 2400。
- 世界页依据：`tmp/design-reference-world-1to1.png`。
- 实际截图：`tmp/audit-22-current-timeline.png`、`tmp/audit-23-current-people.png`、`tmp/audit-24-current-world.png`、`tmp/audit-25-current-profile.png`；本轮再次在 Pixel 8（1080 × 2400）检验人物页与地图页。

## 已确认

- 底部仍是“岁月 / 人物 / 天下 / 我的”四栏，选中态、木刻图标与纸本底色保持一致。
- 世界页继续使用已确认的 1:1 地图构图；标题、明代／现代切换、图例、两京、时间尺和下方事件板没有被原生页面标题二次覆盖。顶部留白是 Android 状态栏安全区，不另叠加应用标题。
- 岁月页保留年号轨与月份点，事件可展开阅读详情、参与人物、影响和出处。
- 人物页现有“朝代档案 / 人物 / 关系”二级页；人物按六分类（帝王、内廷、封爵、朝臣、将帅、文苑）筛选，机构移至天下页。

## 尚未达到发布标准的部分

- 世界页的明代主图目前是确认过的栅格参考图。后端已提供图层契约，但行政边界、邻国势力和年代切片还没有转为可查询的 PostGIS / GeoJSON 数据。
- 内容服务当前有 17 年号、51 个按年事件、748 位明朝人物（含南明与后妃、藩王分类）、72 条关系和 12 个机构；调试版 Android 已从服务端单一内容源载入这些资料，断网时才回退本地种子名录。
- 关系页改为“按人物聚焦”的网络：选择任意已有关系的人物，可查看其直接关联，关系簿仍保留全量条目。该方式避免把数十名人物压缩在一张不可读的总览图中。
- 已接入的 13 幅绢本示意像继续保留；按最新产品决定，不再新增生成画像。其余人物显示“待补图像”，不能标作传世画像。
- 事件和人物条目的卷次、版本、引文位置仍标为“待卷次校核”，目前只能作为导览，不能作为学术定论。
