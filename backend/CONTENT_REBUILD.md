# 人物与事件重建规范

本轮重建使用统一栏目，而不向最终用户显示资料采集方式。每段文字的出处保存在
`content_reference`，供编辑校核、修订和版权审查。

## 人物栏目

1. `basic`：基本信息（姓名、字/号、籍贯、生卒、身份）
2. `life`：生平经历（按早年、转折、晚年组织）
3. `career`：仕历／军旅（任职、地点、升迁、罢黜）
4. `achievement`：主要事迹（政务、战役、著作或学术贡献）
5. `family`：家族与关系（父母、配偶、子嗣、重要人物）
6. `assessment`：历史评价（同时代记载、后世研究与有据争议）

## 事件栏目

1. `background`：背景
2. `course`：经过
3. `people`：相关人物
4. `result`：结果
5. `impact`：历史影响
6. `references`：参考资料说明

每个栏目只在有可靠材料时展示。检索优先级为原始史料、可公开核查的学术或文博资料、
维基文库／维基百科的交叉索引；百科页面只用于查找线索与比对，不将未经核对的说法写成事实。
